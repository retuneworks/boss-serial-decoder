BOSS PEDAL DATING GUIDE

How BOSS serial number dating works

BOSS compact pedal serial formats changed over time. This decoder does more than convert a code into a date: it also checks whether the selected model could reasonably have been in production at that time.

Where is the serial number?

On many pedals, the serial appears on a label on the base or inside the battery compartment. Read the printing carefully and make sure the model and serial belong to the same pedal before entering them.

Four- and five-digit batch codes

Short batch codes appear on early pedals. The leading digits are used to estimate a manufacture month. If a code appears to have five digits, check for spacing, faint printing, or a transcription error.

Six-digit serial numbers

Six numeric digits are common on pedals from the 1980s. A date code within the number can be converted to a month and year, but the number alone cannot confirm that one specific serial was issued.

Serial numbers with letters

The decoder supports two letters followed by five digits and the later mixed letter-and-number format. The digit 0 and letter O are different; O is reserved in the manufacture-date code position and produces an input error.

Why check the model and serial together?

A serial can decode to a valid month that predates a model's introduction or falls after its production ended. Checking both fields helps identify a date that conflicts with the model's documented availability.

Production-period compatibility

The result is classified as a match, additional check recommended, or conflict using documented possible production periods. Unknown models, invalid formats, impossible dates, reserved O codes, and future dates remain input errors.

When the serial and sales period conflict

If the date falls outside even the broad possible production period, the result states that the serial and period conflict. Mistyped details, incomplete records, unusual distribution, or a replacement label are among several possibilities; the tool does not determine authenticity.

Physical details are supporting evidence

Labels, Made in Japan or Made in Taiwan markings, ACA or PSA markings, circuit boards, and component date codes may help with a separate inspection. They are not inputs to this decoder and should be treated only as supporting evidence.

Every result is an estimate

This tool validates the serial format, date code, and compatibility with the model's possible production period. It cannot verify that a particular serial was issued or establish whether a pedal is authentic.
