ABOUT THIS SITE

About this serial number decoder

A free, unofficial tool that estimates the manufacture date of a BOSS compact pedal and checks it against the model's possible production period.

How the result is calculated

The tool estimates a manufacture month from the model and serial number. It does not stop at a simple serial conversion: it also compares the date with documented possible production periods for that model.

A date can match, need an additional check because sources differ, or conflict with the possible production period. Format problems remain separate input errors rather than compatibility warnings.
