# 画面・判定仕様

## 入力
1. 型式
2. シリアルナンバー

製造国、ラベル、ネジ、アダプター、IC、基板、部品デイトコード、備考は入力できないようにします。

## 正常な出力
```text
推定製造年月
1982年1月

販売期間（参考）
製造可能期間／判定基準
整合性判定：✅ 整合性あり
```

## 3段階の整合性判定

シリアルから推定する年月は原則として製造年月なので、販売期間とは別に登録した製造可能期間を優先します。

- `consistent`: 確実性が高い製造期間内。`✅ 整合性あり`
- `needs-review`: 資料によって評価が分かれる期間内。`⚠️ 要追加確認`
- `inconsistent`: 広く見積もった製造可能期間外。`❌ 整合性なし`

製造期間データが未登録の型式のみ、従来の販売期間を判定基準として使用します。

## 製造可能期間と矛盾する場合

シリアル形式から年月を推定できても、その年月が登録された製造可能期間外なら次を表示します。

```text
推定製造年月
1994年11月

整合性判定：❌ 整合性なし
製造可能期間とシリアルが矛盾しています。
```

型式・シリアルの誤入力、シリアルラベルの交換、登録データ不足などの可能性を短く表示します。偽物や改造品とは断定しません。

## 入力エラー
次を区別して表示します。

- 未登録または存在しない型式表記
- 対応していない桁数・文字構成のシリアル
- 年月コードとして成立しないシリアル
- 現行形式の年月コード位置に使用されない英字O
- 現在より未来の年月を示すシリアル

特定のシリアルが実際に工場で発行されたかは判定できません。形式、年月コード、製造可能期間との整合性を検証します。

## 資料差注記

`production-periods.json` で `hasSourceDiscrepancy: true` の型式は、判定結果と独立して常に「⚠️ 資料間で製造期間に差異があります。」を表示します。資料差注記が表示されること自体は、`needs-review` 判定を意味しません。

対象型式は CE-2、CS-2、NF-1、VB-2、OC-2、CE-3、DM-3、HF-2、PN-2、PW-2、PS-2、DC-3、OD-1 です。

## 対応形式
- 4桁
- 6桁
- 英字2桁＋数字5桁
- 英字1桁＋数字1桁＋英字1桁＋数字4桁
- 2022年7月以降の英字O欠番補正

## DS-1の販売休止期間
DS-1は日本国内で販売休止期間がありましたが、台湾生産と海外販売が継続していたため、整合性判定では1978年6月以降の継続モデルとして扱います。
