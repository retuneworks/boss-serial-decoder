# 画面・判定仕様

## 入力
1. 型式
2. シリアルナンバー

製造国、ラベル、ネジ、アダプター、IC、基板、部品デイトコード、備考は入力できないようにします。

## 正常な出力
```text
推定製造年月
1982年1月

販売期間との整合性：あり
```

## 販売期間と矛盾する場合
シリアル形式から年月を推定できても、その年月が登録された型式の販売期間外なら次を表示します。

```text
推定製造年月
1994年11月

販売期間との整合性：なし
販売期間とシリアルが矛盾しています。
```

型式・シリアルの誤入力、シリアルラベルの交換、登録データ不足などの可能性を短く表示します。偽物や改造品とは断定しません。

## 入力エラー
次を区別して表示します。

- 未登録または存在しない型式表記
- 対応していない桁数・文字構成のシリアル
- 年月コードとして成立しないシリアル
- 現行形式の年月コード位置に使用されない英字O
- 現在より未来の年月を示すシリアル

特定のシリアルが実際に工場で発行されたかは判定できません。形式、年月コード、販売期間との整合性を検証します。

## 対応形式
- 4桁
- 6桁
- 英字2桁＋数字5桁
- 英字1桁＋数字1桁＋英字1桁＋数字4桁
- 2022年7月以降の英字O欠番補正

## DS-1の販売休止期間
DS-1は日本国内で販売休止期間がありましたが、台湾生産と海外販売が継続していたため、整合性判定では1978年6月以降の継続モデルとして扱います。
